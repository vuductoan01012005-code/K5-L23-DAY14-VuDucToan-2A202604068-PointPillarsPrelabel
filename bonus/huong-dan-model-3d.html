Chạy PointPillars bên trong CVAT (Hướng 2, tối đa +3)

Bonus Day 14, tùy chọn. Làm tối đa 45 phút. Hết giờ mà chưa chạy được thì nộp báo cáo vướng mắc (+1).

Mục tiêu: CVAT tự sinh cuboid cho task 3D của bạn bằng một serverless function (Nuclio) bọc PointPillars, rồi so số box đó với pred_*.json chạy offline.

An toàn: dashboard Nuclio (cổng 8070) không có đăng nhập. Chỉ bind vào 127.0.0.1, không mở ra mạng.

1. Bật serverless cho CVAT

Bạn đã chạy CVAT bằng Docker cho phần bắt buộc. Trong đúng thư mục cvat đó, chạy lại kèm file serverless để có Nuclio (dữ liệu và task cũ vẫn giữ nguyên):

docker compose -f docker-compose.yml \
  -f components/serverless/docker-compose.serverless.yml up -d

Cài nuctl đúng phiên bản dashboard (xem tag image quay.io/nuclio/dashboard trong file serverless compose). Mac Apple Silicon: dùng image dashboard có hậu tố -arm64 để function build native, nhanh hơn nhiều so với giả lập amd64.

Dùng luôn task 3D đã tạo ở phần bắt buộc (hoặc tạo task mới bằng scripts/vf_cvat.py) và ghi lại task id.

2. Viết function

Một thư mục gồm function.yaml, main.py và bản sao thư mục vf_pp/ cùng trọng số. Nuclio chỉ build những gì nằm trong thư mục này.

Input CVAT gửi sang

Với task 3D, CVAT gửi file PCD của frame, mã hóa base64 trong body["image"]. PCD của lab có các trường x y z rgb dạng binary. Kênh rgb chứa mức xám đã nén log của intensity (xem vf_common.intensity_gray), nên bạn phải tự đảo ngược hàm đó để có lại intensity xấp xỉ. Không đảo thì model vẫn chạy nhưng sẽ ra ít box hơn.

Output phải trả về

[{"type": "cuboid", "label": "Car", "confidence": "0.81",
  "points": [x, y, z, 0, 0, yaw, length, width, height, 0, 0, 0, 0, 0, 0, 0]}]

Mảng points có đúng 16 số: tâm, góc xoay (radian, quay quanh trục z), kích thước, cộng 7 số 0 đệm. Tên label phải trùng với label của task.

Phần chính của function.yaml

metadata:
  name: pp-<ID>
  namespace: nuclio
  annotations:
    name: PointPillars <ID>
    type: detector
    supported_shape_types: cuboid
    spec: |
      [{"id": 1, "name": "Car", "type": "cuboid"},
       {"id": 2, "name": "Pedestrian", "type": "cuboid"}]   # khớp label của task
spec:
  runtime: python:3.10
  handler: main:handler
  eventTimeout: 120s
  build:
    baseImage: python:3.10-slim
    directives:
      preCopy:
        - kind: RUN
          value: pip install --no-cache-dir numpy torch --extra-index-url https://download.pytorch.org/whl/cpu
  triggers:
    myHttpTrigger:
      kind: http
      numWorkers: 1
      attributes:
        maxRequestBodySize: 33554432   # PCD lớn hơn mặc định 4 MB

3. Deploy

nuctl create project cvat --platform local
nuctl deploy --project-name cvat --path ./my-function \
  --file ./my-function/function.yaml --platform local
nuctl get functions --platform local     # cột STATE phải là "ready"

Vào CVAT, mở trang Models: function của bạn phải xuất hiện ở đó. Nếu không thấy, xem log container cvat_server và nuclio.

4. Gọi qua API

Hộp thoại Automatic annotation khóa ô chọn model với task 3D và báo "No models available". Một PR mở khóa ô này đã bị CVAT từ chối vì khi đó danh sách sẽ hiện cả model 2D (YOLO, SAM...). Vì vậy hãy gọi thẳng API:

curl -u <user>:<pass> -H "Content-Type: application/json" \
  -X POST http://localhost:8080/api/lambda/requests \
  -d '{"function": "pp-<ID>", "task": <task_id>, "threshold": 0.3, "cleanup": true}'

# theo dõi tiến độ (dùng id trả về ở lệnh trên)
curl -u <user>:<pass> http://localhost:8080/api/lambda/requests/<request_id>

Thay <user>:<pass> bằng tài khoản CVAT local của bạn. Đừng dán mật khẩu vào báo cáo hay video.

5. Kiểm tra và so khớp

  1. Mở job: cuboid phải nằm đúng vị trí trên đám mây điểm. Quay video ngắn màn hình.
  2. Lấy cuboid ra qua GET /api/jobs/<job_id>/annotations. Không nên dựa vào export, vì cuboid dạng shape có thể bị thiếu khi export (cvat#9144). Nếu có export thì kiểm tra lại file.
  3. So với pred_*.json offline: đếm số box của CVAT có tâm cách một box offline cùng label không quá 0,5 m. Ghi rõ cả hai tổng số.

Lệch nhỏ là bình thường, vì intensity khôi phục từ PCD chỉ là xấp xỉ. Đừng viết là pipeline "giống hệt" nếu số không khớp hoàn toàn.

6. Lỗi hay gặp

Triệu chứngThử
Function không hiện trong trang ModelsKiểm tra namespace: nuclio, đúng --project-name cvat, và CVAT được chạy kèm file serverless compose.
Request báo 413 / body too largeTăng maxRequestBodySize.
Timeout ở frame đầuLần đầu phải nạp model. Tăng eventTimeout, hoặc nạp model trong init_context.
Build pip lỗi trên Mac arm64Dùng dashboard -arm64. Nếu thiếu wheel thì pip download sẵn trong preCopy.
Chạy xong nhưng 0 cuboidLabel trong spec không khớp label của task, hoặc threshold quá cao, hoặc quên đảo intensity.
Box lệch hoặc xoay saiKiểm tra thứ tự 16 số và đơn vị góc (radian).
